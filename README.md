# IaC — Mastère 4A - Version BRANCHE 1

Exercices pratiques Infrastructure as Code pour le Mastère Cybersécurité, 4ème année. Ce dépôt réunit tous les travaux pratiques sur 5 jours couvrant Git, Terraform et Ansible.

## Observations

Après modification d'un fichier sans exécuter `git add`, le fichier apparaît dans la section "Changes not staged for commit" du répertoire de travail. Cela signifie que le fichier se trouve dans le **répertoire de travail** mais n'est pas encore dans la zone de staging (index).
