# IaC — Mastère 4A

Infrastructure as Code practical exercises for Cybersecurity Master's degree, year 4. This repository tracks all TP work across 5 days covering Git, Terraform, and Ansible.

## Observations

After modifying a file without `git add`, the file appears in the "Changes not staged for commit" section in the working tree. This means the file is in the **working directory** but not yet in the staging area (index).
